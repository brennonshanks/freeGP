# Tutorials

These examples are meant for learning the workflow, not reproducing the paper.
They use small synthetic datasets so users can run the code without downloading
the full manuscript datasets.

Start with:

```bash
cd tutorials/synthetic_umbrella
python make_dataset.py
python run_reconstruction.py
```

The full paper datasets are expected to live outside this GitHub repository.
See the main `README.md` for the general data layout and command-line entry
points.
